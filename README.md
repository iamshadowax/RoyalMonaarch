# RoyalMonaarch School Management System

A single-file, responsive front-end prototype for a school management platform, built with HTML, embedded CSS, and vanilla JavaScript.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No build step or framework installation is required.

## Demo roles

- **School Admin:** students and teachers, results/report cards, announcements, attendance, fee records, analytics, settings, and notifications.
- **Teacher:** assigned-class score entry, student information and results, attendance, school communications, and notifications. No fee-management or school-settings access.
- **Parent:** fictional linked-child results, attendance, fee balances/payment records, announcements, child switching, and notifications.

The app uses fictional demo data and browser storage for prototype interactions.

## Prototype limitations

This is **not production-ready for real student information**. Browser-side role restrictions are not a security boundary. Production use requires server-side authentication and authorization, a secure database, verified parent-child relationships, audit logs, backups, and properly integrated messaging/payment providers.
